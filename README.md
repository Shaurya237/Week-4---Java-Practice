# LeetCode Practice — Functions & Arrays — Category C

Java solutions for A1–A5.

## Programs
1. `A1_HackathonRegistration/ParticipantDemo.java` — overloaded constructors and `this()` chaining.
2. `A2_CanteenInventory/ItemRestockDemo.java` — `this` keyword and batch restocking.
3. `A3_ParkingFine/ParkingFineDemo.java` — `final` methods, parallel arrays, and if-else.
4. `A4_MembershipCard/MembershipCardDemo.java` — static block and creating objects in a loop.
5. `A5_PaymentDispatch/PaymentDispatchDemo.java` — `instanceof`, inheritance, card processing fee, running total.

## Compile and run
Compile each `.java` file from its own directory. Example:

```bash
cd A1_HackathonRegistration
javac ParticipantDemo.java
java ParticipantDemo
```

Each exercise is in a separate directory so classes with overlapping names can be compiled independently.
